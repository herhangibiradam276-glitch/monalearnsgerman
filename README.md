# monalearnsgerman - German Exam Resource Hub

A modern, high-converting, mobile-friendly Resource Hub webpage for **monalearnsgerman**, connecting German language learners with structured exam blueprints and direct exam practice on [Zertifly.com](https://zertifly.com).

## ?? Features
- **Strategy & Study Blueprints:** Curated guides for General German, Goethe-Zertifikat, telc, and TestDaF (A1 to C1).
- **Downloadable PDF Playbooks:** *The Smart German Playbook* (A1-A2 & B1-B2 editions).
- **Zertifly Practice Integration:** Timed exam practice and AI evaluation for speaking & writing.
- **Creator DM Support:** Direct connection to Instagram @monalearnsgerman.
- Built with HTML5 and Tailwind CSS.
